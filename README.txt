EVROPA 2 – PRÁVNÍ STRÁNKY

Soubory:
- index.html = Podmínky používání
- privacy.html = Zásady ochrany osobních údajů

PŘED PUBLIKOVÁNÍM:
1. V OBOU souborech nahraď [DOPLŇ JMÉNO NEBO NÁZEV] svým skutečným jménem/názvem provozovatele.
2. Nahraď [DOPLŇ E-MAIL] funkční kontaktní adresou.
3. Nahraď [DOPLŇ ROK] aktuálním rokem.
4. Ověř dobu uchování Render logů a zda kód skutečně neukládá další údaje. Texty musí odpovídat realitě.

GITHUB PAGES:
1. Na GitHubu vytvoř nový veřejný repozitář, např. evropa2-legal.
2. Nahraj index.html a privacy.html přímo do kořene repozitáře.
3. Otevři Settings > Pages.
4. V Build and deployment vyber Deploy from a branch.
5. Vyber branch main a folder /(root), klikni Save.
6. Počkej na zveřejnění.

Adresy budou mít tvar:
https://TVUJ-GITHUB-UCET.github.io/evropa2-legal/
https://TVUJ-GITHUB-UCET.github.io/evropa2-legal/privacy.html

DISCORD DEVELOPER PORTAL:
- URL podmínek = první adresa
- URL zásad ochrany osobních údajů = druhá adresa
- Interactions Endpoint URL nech prázdné, pokud používáš Gateway.
- Role Connections Verification URL nech prázdné, pokud nepoužíváš propojené role.

Jde o obecné vzory, nikoli právní stanovisko. Před zveřejněním ověř skutečné zpracování údajů a podle potřeby texty konzultuj s právníkem.
